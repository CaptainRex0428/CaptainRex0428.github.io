# 设计系统（暗夜流光）

本文是站点视觉与交互的唯一说明文档，替代早期 `.claude/memories/` 里的散落记录。设计令牌的**实际值**以 `src/styles/global.css` 为准，本文只解释规则与用法。

## 定位

深色、克制、偏"技术作品集"。主体是近黑背景加一层橙色强调，靠层级与留白撑质感，不靠特效堆叠。

## 颜色

| 角色 | 变量 | 用途 |
|---|---|---|
| 主背景 | `--bg-base` | 页面底色 |
| 抬升面 | `--bg-elevated` | 卡片、浮层 |
| 分割 | `--bg-border` | 边框、分隔线 |
| 强调 | `--accent` | hover、主按钮、链接高亮、分类标签 |
| 强调光晕 | `--accent-glow` | hover 时的柔光 |
| 文字 | `--text-primary` / `--text-secondary` / `--text-muted` | 三级文字层次 |

规则：

- 层级优先用**透明度与灰度**区分，不新增颜色；
- 橙色只做强调，不铺大面积；
- 禁止 AI 常见的紫蓝渐变、beige+brass 组合；
- 文字对比度不低于 WCAG AA。

## 排版

- 中文 Noto Sans SC，英文 Inter，代码 JetBrains Mono；
- 标题 600–700，正文 400，正文行高 1.7；
- 标题宽度用 `ch` 约束（如 `15ch`），避免一行过长。

## 动效

| 令牌 | 值 | 场景 |
|---|---|---|
| `--transition-fast` | 0.15s `cubic-bezier(.4,0,.2,1)` | 颜色、边框 |
| `--transition-base` | 0.25s 同曲线 | hover 位移 |
| `--transition-slow` | 0.5s `cubic-bezier(.16,1,.3,1)` | 图片缩放 |

规则：

- 只动 `transform` / `opacity`，不动布局属性；
- 必须支持 `prefers-reduced-motion`，开启后动画降到 0.01ms；
- 滚动动画用 IntersectionObserver，元素只播一次；
- 每个动画都要有理由（层级、叙事、反馈），不做无意义抖动。

## 卡片与高度稳定

博客/作品列表的卡片必须**同一行等高**，靠这条链撑住：`.content-item` → 卡片容器 → 链接 → `.card`。

- 封面卡固定 `16 / 9`；
- 标题 clamp 2 行；
- 描述：有封面 5 行、无封面 3 行；
- 标签区**预留 3 行**高度，1/2/3 行标签都不改变卡片高度；
- 超过 3 行时在浏览器端测量并折叠，第 3 行显示 `...` —— 必须浏览器端算，因为换行取决于容器宽度、字体、chip 内边距。

## 可达性

- 语义化标题层级与 landmark；
- 键盘焦点可见；
- 用 `100dvh` 而非 `100vh`，避免移动端地址栏导致的跳动；
- 动效降级见上。

## 布局

- 容器最大宽 1200px；
- 间距以 8px 为基准（8/16/24/32/48/64/80/120）；
- 区块纵向间距 80px（桌面）/ 48px（移动）；
- 断点：480 / 768 / 1024 / 1280。
