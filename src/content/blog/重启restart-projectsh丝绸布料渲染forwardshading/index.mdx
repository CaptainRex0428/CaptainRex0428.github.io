上一篇文章我们基本弄清楚了布料的原理，但是在实现的时候碰到了一个问题，就是做半透丝绸的时候碰到了爆亮的问题，为了搞清楚这个问题开始绕了很大一圈，梳理了前向渲染管线的顺序（当然这个就当再次学习了——FPixelShaderInOut_MainPS --> GetForwardDirectLightingSplit --> GetDynamicLightingSplit --> AccumulateDynamicLighting --> IntegrateBxDF --> CustomClothBxDF），我以为是BxDF在前向中的多次积累导致的问题，但是在单光源下也出现了问题，所以核心并不是这个问题。

![图片](https://pic1.zhimg.com/v2-2141cbebf4e557a2bf73a42c502e1fea_1440w.jpg)

后来逐步试错、控制变量，发现只有SpecAnisotropy这个东西会出现爆亮的问题，所以又去排查了一遍BxDF的算法，发现是因为在Translucent和前向的状态下的渲染中bHasAnisotropy并未得到正确传入，Tangent计算错误（为0），所以我们不应该在BxDF中直接保留这个过程，而是将其隔离出来

所以修改了一下ShadingModels.ush中我们自定义的CustomClothBxDF函数

这里我们使用宏将Translucent的初始化过程进行了隔离

进一步我们发现一个问题，就是前向渲染中的高光的计算并不止于ForwardDirectLighting的计算结果（这个计算和声明在BasePassPixelShader.ush中）

![图片](https://pic1.zhimg.com/v2-617499837610b620b99412f99ae75ee2_1440w.jpg)

另外还有一层高光和颜色的叠加计算

![图片](https://pic1.zhimg.com/v2-1ed77d2817505cf461de0ab01f6f636c_1440w.jpg)

FPixelShaderInOut_MainPS --> GetImageBasedReflectionLighting --> GetImageBasedReflectionSpecular（IBL）--> AccumulateDynamicLighting --> IntegrateBxDF --> CustomClothBxDF

但是这一层高光会对布料的高光计算结果产生影响，我们尝试将这个影响放大就会发现问题

当然我们可以去改变这个高光的算法（可能会再单独写一篇）

但是在这里这种镭射皮料的效果是可以增益我们的丝绸质感表达的，所以我们在丝绸中可以保留下来，但是在布料中是接受不了的

![图片](https://pica.zhimg.com/v2-852f42410e6f69443e917aa87ed80980_1440w.jpg)

简单一点，我们用插值的方式来简单处理这个问题即可，所以加入了这一段

```
if (GBuffer.ShadingModelID == SHADINGMODELID_CLOTH)
{
ReflectionColor *= saturate(GBuffer.Anisotropy) * (1 - saturate(Opacity));
}
```
