这是一个使用 Three.js 构建的交互式粒子系统。

## 特性

- 支持自定义粒子数量、颜色、大小
- 基于 GPU 加速的性能优化
- 实时参数调整
- 多种预设效果

## 技术实现

使用 GLSL 着色器实现粒子动画，通过自定义顶点着色器控制粒子的位置和大小变化。

```glsl
// 粒子顶点着色器示例
uniform float time;
uniform float size;

void main() {
  vec3 pos = position;
  pos.y += sin(time + position.x) * 0.5;
  gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
  gl_PointSize = size * (1.0 + sin(time * 2.0));
}
```
